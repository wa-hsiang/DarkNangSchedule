# 峴港行程 DarkNangSchedule

9/14–9/17 峴港四天行程的單頁靜態網站。深色主題，行程以時間軸呈現，每個地點都標上所在的分區代號與 Google Maps 連結，讓人在路上用手機就能確認「下一站在哪一區、怎麼走」。

線上版：<https://wa-hsiang.github.io/DarkNangSchedule/>

## 檔案結構

`index.html` 就是整個網站。HTML、CSS、SVG 地圖全部寫在這一個檔案裡，沒有建置流程，也沒有任何外部相依套件或圖片資源。

預覽方式是直接用瀏覽器開啟 `index.html`，不需要起本機 server。單檔的好處是改一行字就能立刻看到結果，也不會發生某個資源忘了 commit、線上版卻壞掉的狀況。

## 分區規則 A～H

韓江把峴港市區分成東西兩岸，三座橋由北往南再把每一岸各切成四段，合計八區。行程中每個地點都掛一個區域標籤，點標籤會跳到頁面下方的分區地圖。

| 區 | 位置 | 這一區的地點 |
|---|---|---|
| A | 西岸・韓江橋以北 | LUK LAK、Madame Lân、Bunny Bar、New Phương Đông |
| H | 東岸・韓江橋以北 | Vincom Plaza、Be Man、Ciela Sky Bar |
| B | 西岸・韓江橋～龍橋 | 漢市場、Pizza 4P's、大教堂、占婆博物館、Bạch Đằng、ON! Cocktail |
| E | 東岸・韓江橋～龍橋 | 美溪海灘、MAY COFFEE、Mộc Quán、Brilliant Seafood、海灘酒吧、Fatfish |
| C | 西岸・龍橋～陳氏理橋 | 目前沒有行程落在這一區 |
| F | 東岸・龍橋～陳氏理橋 | Bếp Cuốn、山茶夜市、龍橋、Bar Flow 一帶酒吧 |
| D | 西岸・陳氏理橋以南 | 目前沒有行程落在這一區 |
| G | 東岸・陳氏理橋以南 | An Thượng 一帶咖啡、餐廳、LUXURY、酒吧 |

圖例中 C 與 D 兩格即使沒有行程也保留並標示「目前沒有行程落在這一區」。拿掉它們會讓人以為分區規則本身有缺漏，反而得回頭數地圖上的格子才能確認。

## 頁面區塊

- 標題區：日期範圍與這趟行程的主題標籤
- 日期卡片：四張卡片，點擊跳到對應的那一天
- DAY 1～DAY 4：每天一節，內含當天路線與時間軸
- 備案行程（`#optional`）：沒有綁定日期與時間的候選地點，可視當天狀況插入
- 分區地圖（`#map`）：A～H 的 SVG 示意圖與圖例，所有區域標籤都連到這裡

## 修改行程

每一列行程是一個 `.row`，左邊是時間、右邊是內容。編輯時會用到的 class：

- `.time`：有明確時間的列，前面帶一個發光圓點
- `.time.cont`：沒有明確時間的列（例如「抵達後」或備案行程），圓點與強調色會拿掉，避免看起來像一個已經談定的時間點
- `.zone-tag.zone-X`：區域標籤，`X` 是 A～H，顏色由 CSS 變數決定，每一區一個顏色
- `.link`：地點連結，一律指向 Google Maps 搜尋網址並以新分頁開啟

每一節（`.day`）的 `--acc` 變數決定該節的強調色，日期卡片上的同色設定要一起改，否則卡片與該日區塊的顏色會對不起來。

改完直接 commit 並 push 到 `main`，GitHub Pages 會自動重新發佈。
